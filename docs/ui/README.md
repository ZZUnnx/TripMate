# TripMate 앱 UI 정리

이 문서는 현재 Flutter 앱에 반영된 주요 모바일 UI 화면과 컴포넌트 구조를 정리한다.

## 공통 레이아웃

- 기준 화면 폭은 `430px`이며, `ResponsiveScope`와 `context.rs()`를 사용해 화면 크기에 맞춰 비율 조정한다.
- 주요 배경색은 `#F7FAF9`, 카드 배경은 `#FFFFFF`, 구분선은 `#DCE6E3`를 사용한다.
- 주요 브랜드 컬러는 `#148776`, 강조 텍스트/활성 상태는 `#0B5F55`를 사용한다.
- 하단 네비게이션은 4개 탭으로 구성한다.
  - 홈
  - 채팅
  - 캘린더
  - 정산

관련 파일:

- `frontend/lib/widgets/common/responsive.dart`
- `frontend/lib/widgets/home/bottom_navigation.dart`
- `frontend/lib/screens/app_shell.dart`

## 하단 네비게이션

공용 하단 네비게이션은 전체 화면 하단에 고정된다.

- 높이: `70`
- 상단 구분선: `#DCE6E3`
- 활성 아이콘 배경: `#DDF3EE`
- 활성 색상: `#0B5F55`
- 비활성 색상: `#8A9895`
- 탭 인덱스:
  - `0`: 홈
  - `1`: 채팅
  - `2`: 캘린더
  - `3`: 정산

## 홈 화면

홈 화면은 여행 진행 현황을 대시보드 형태로 보여준다.

주요 섹션:

- 상단 앱 헤더
- 사용자 프로필 카드
- 진행 중인 여행 카드
- 확인이 필요한 항목
- 빠른 통계
- 예정된 여행
- 이번 달 일정

관련 파일:

- `frontend/lib/screens/home/home_screen.dart`

## 채팅 목록

채팅 목록 화면은 여행 채팅방을 진행 중인 여행과 지난 여행으로 나누어 보여준다.

주요 구성:

- 상단 헤더
- 검색 바
- 진행 중인 여행 채팅방 목록
- 지난 여행 채팅방 목록
- 채팅방 생성 진입 버튼

관련 파일:

- `frontend/lib/screens/chat/chat_screen.dart`

## 채팅방 상세

채팅방 상세 화면은 여행 대화, 메시지 입력, 확장 메뉴, AI 요약, 채팅방 정보를 포함한다.

주요 구성:

- 채팅방 헤더
  - 뒤로가기
  - 채팅방 제목
  - AI 요약 버튼
  - 검색/메뉴 버튼
- 메시지 영역
  - 날짜 구분
  - 수신/발신 메시지 버블
- 메시지 입력창
  - 확장 메뉴 열기 버튼
  - 입력 필드
  - 전송 버튼
- 하단 확장 메뉴
  - AI 요약
  - 사진, 카메라, 파일, 위치
  - 일정, 정산, 투표, 연락처
- 채팅방 정보 드로어
  - 여행 대표 이미지
  - 참여자 목록과 친구 초대 버튼
  - 공지, 공유 일정, 여행 앨범, 파일, 링크, 정산 현황 등
- AI 요약 바텀시트
  - 분석된 일정/장소/예약/예산 후보 표시
  - 공유 일정 추가 버튼

관련 파일:

- `frontend/lib/screens/chat/chat_detail_screen.dart`

## 캘린더 메인

통합 캘린더 화면은 여행 공유 일정을 한눈에 보여준다. 개인 일정은 UI 범례와 화면 구조만 남아 있으며, 개인 일정 전용 데이터 모델/API는 추후 확장한다.

주요 구성:

- 상단 헤더
  - 통합 캘린더
  - 공유 여행 일정 안내 문구
  - 일정 추가 버튼
- 월 이동 컨트롤
- 개인 일정/여행 공유 일정 범례
- 월간 캘린더 그리드
  - 선택일 강조
  - 여행 공유 일정 마커
- 선택일 일정 목록
  - 공유 여행 일정
  - 확정 상태와 공유 일정 표시
- 데이터 연결
  - `GET /api/trips`로 접근 가능한 여행 목록을 조회한다.
  - 여행별 `GET /api/trips/{tripId}/schedules` 결과를 합쳐 월간 캘린더에 표시한다.
  - 로딩, 인증 필요, API 오류 상태를 캘린더 본문 카드로 표시한다.
- 일정 추가
  - 우측 상단 추가 버튼을 누르면 일정 추가 바텀시트가 열린다.
  - 여행, 제목, 날짜, 시간, 카테고리, 장소, 링크, 메모를 입력해 `POST /api/trips/{tripId}/schedules`로 저장한다.

관련 파일:

- `frontend/lib/screens/calendar/calendar_screen.dart`

## 캘린더 상세

캘린더 상세 화면은 여행 전체 타임라인을 일자별로 보여준다.

주요 구성:

- 상세 헤더
  - 뒤로가기
  - 여행 이름
  - 여행 기간
  - 일정 추가 버튼
- 여행 기간 요약 카드
  - 날짜 범위
  - 확정 상태
  - 일정 개수
- 전체 캘린더에서 보기 버튼
- 일정 정산 준비 중 카드
- 여행 전체 타임라인
  - API 일정 데이터를 날짜별 섹션으로 그룹화
  - 시간, 장소, 확정 상태 표시
  - 일정 카드를 누르면 날짜, 시간, 장소, 메모, 링크 상세정보가 카드 내부에서 펼쳐진다.
  - 다시 누르면 상세정보가 부드럽게 접힌다.
- 지도에서 보기 준비 중 안내

진입 방식:

- 캘린더 메인 화면의 일정 카드를 누르면 해당 일정이 속한 여행의 상세 타임라인으로 이동한다.
- 채팅방 서랍 메뉴의 `공유 일정`을 누르면 해당 채팅방의 여행 일정 상세 타임라인으로 이동한다.

관련 파일:

- `frontend/lib/screens/calendar/calendar_screen.dart`
- `frontend/lib/models/trip_schedule.dart`
- `frontend/lib/services/schedule_service.dart`

## 정산 화면

정산 화면은 여행 지출과 정산 상태를 탭별로 보여준다.

공통 구성:

- 상단 헤더
  - 여행 정산
  - 제주 봄 여행 · 여행 종료
  - 다운로드 버튼
- 총지출 요약 카드
  - 총지출 금액
  - 1인 평균
  - 정산 대상
  - 검토 완료 상태
- 탭
  - 한눈에
  - 결제자별
  - 장소별
- 내가 보낼 금액 / 내가 받을 금액
- 정산 완료로 표시 버튼

### 한눈에 탭

전체 정산 상태를 요약한다.

- 결제자별 내역 일부
- 장소별 지출 요약
- 내가 보낼/받을 금액

### 결제자별 탭

결제자를 기준으로 지출 내역을 보여준다.

- 민지
- 나
- 서준
- 하늘

각 행은 결제 건수와 총 결제 금액을 표시한다.

### 장소별 탭

장소를 기준으로 지출 규모와 상세 결제 내역을 보여준다.

- 장소별 지출 바 차트
  - 숙소
  - 렌터카
  - 성산항
  - 식당
  - 관광지
- 장소별 결제 내역
  - 장소 태그
  - 결제자
  - 날짜
  - 금액

관련 파일:

- `frontend/lib/screens/settlement/settlement_screen.dart`
- `frontend/lib/widgets/settlement/settlement_result_sheet.dart`

## 구현 메모

- Figma에는 일부 화면에 5개 하단 탭이 남아 있지만, 현재 앱 구현은 사용자의 최신 요청에 맞춰 4개 탭을 기준으로 한다.
- 정산 화면 헤더의 `AI 분류 완료` 배지는 제거된 상태다.
- 정산 탭은 실제 상태 전환이 가능하며, 각 탭은 같은 화면 안에서 내용을 바꿔 보여준다.
- 캘린더 상세는 별도 라우트 등록 없이 캘린더 화면 내부에서 `MaterialPageRoute`로 진입한다.
- 2026-10-01 기준 캘린더는 AI 일정 후보 흐름을 제외하고 여행 공유 일정 조회/상세 타임라인 연결까지 완료했다. 일정 추가/수정 UI 폼과 개인 일정 API는 후속 작업이다.
- 2026-10-01 기준 채팅방 나가기 기능은 아직 연결하지 않았다.

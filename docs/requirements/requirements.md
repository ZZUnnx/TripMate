# 요구사항 정의서

## 핵심 기능
1. 회원가입 / 로그인
- 회원가입 시 유효성 검증
- 로그인 후 1시간동안 로그인 유지

2. 여행방 생성

3. 여행 멤버 초대

4. 실시간 채팅

5. 일정 등록 및 관리

6. AI 채팅 분석

7. AI 일정 후보 생성

8. 사용자 승인 후 일정 확정

9. 장소 및 지도 링크 관리

## 작업 기록

### 2026-09-20 실시간 채팅 STOMP 적용

- Spring Boot에 `spring-boot-starter-websocket` 의존성을 추가했다.
- 백엔드에 STOMP 엔드포인트 `/ws/chat`를 추가했다.
- 클라이언트 전송 destination은 `/app/trips/{tripId}/messages`로 정했다.
- 클라이언트 구독 destination은 `/topic/trips/{tripId}/messages`로 정했다.
- STOMP `CONNECT` 헤더의 JWT를 검증하고, 여행방 구독 시 접근 권한을 확인하도록 했다.
- 기존 REST 메시지 조회 API는 유지하고, 실시간 송수신만 STOMP로 처리하도록 Flutter 화면을 연결했다.

### 2026-10-01 캘린더 여행 공유 일정 연결

- AI 일정 후보 생성/승인 흐름은 제외하고 확정 일정 CRUD와 캘린더 조회 연결을 먼저 진행했다.
- 백엔드에 내 여행 목록 조회 API `GET /api/trips`를 추가했다.
- 백엔드에 확정 일정 API를 추가했다.
  - `GET /api/trips/{tripId}/schedules`
  - `POST /api/trips/{tripId}/schedules`
  - `PATCH /api/schedules/{scheduleId}`
  - `DELETE /api/schedules/{scheduleId}`
- 일정 API는 기존 여행방 접근 권한 확인 로직을 재사용해, 여행방 생성자 또는 멤버만 조회/등록/수정/삭제할 수 있도록 했다.
- Flutter에 여행/일정 모델과 `ScheduleService`를 추가했다.
- 캘린더 메인은 목데이터 대신 `GET /api/trips`와 여행별 일정 목록을 합쳐 월간 캘린더와 선택일 일정 목록을 표시하도록 연결했다.
- 캘린더 상세는 선택한 일정의 `tripId`를 기준으로 해당 여행의 전체 타임라인을 보여주도록 연결했다.
- 개인 일정 전용 API, 일정 추가/수정 UI 폼, 지도/정산 비용 연결은 후속 작업으로 남겼다.

### 2026-10-01 채팅방/캘린더 UX 정리

- 채팅방 생성 화면은 채팅방 이름만 입력해서 만들 수 있도록 단순화했다.
  - 여행지, 시작일, 종료일 입력은 제거했다.
  - DB의 `trips.destination`, `trips.start_date`, `trips.end_date`는 NULL 허용이 필요하다.
- 채팅방 상세의 첫 메시지 상단에 표시되던 하드코딩 여행 정보 핀 카드(`우도 배편 · 4/19 오전 후보`)를 제거하고 날짜 구분만 남겼다.
- 채팅방 서랍 메뉴의 참여자 영역에 친구 초대 버튼을 추가했다.
  - 이메일 입력 바텀시트에서 `POST /api/trips/{tripId}/members`를 호출한다.
  - 초대 성공 후 참여자 목록을 다시 조회한다.
- 채팅방 서랍 메뉴의 공유 일정 버튼을 실제 여행 일정 상세 화면으로 연결했다.
  - `GET /api/trips/{tripId}/schedules`로 해당 채팅방의 일정을 불러온다.
  - 일정이 있으면 캘린더 상세 화면으로 이동하고, 뒤로가면 기존 채팅방으로 돌아온다.
- 캘린더 메인 우측 상단 버튼을 일정 추가 버튼으로 변경했다.
  - 여행 선택, 제목, 날짜, 시간, 카테고리, 장소, 링크, 메모를 직접 입력해 일정을 추가한다.
- 캘린더 상세의 별도 선택 일정 상세 카드는 제거했다.
  - 여행 전체 타임라인의 일정 카드를 누르면 상세정보가 카드 안에서 펼쳐지고, 다시 누르면 부드럽게 접힌다.
  - 접힘/펼침 모두 `SizeTransition`과 `FadeTransition`으로 자연스럽게 처리한다.
- 캘린더 상세의 정산 카드는 유지하되, 연동된 비용 데이터가 없으면 총액과 1인 기준을 `0원`으로 표시한다.
- 채팅방 나가기 기능은 아직 연결하지 않았으며 후속 작업으로 남겼다.
